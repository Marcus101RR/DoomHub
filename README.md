# Doom Hub

A lobby for playing Doom online with friends: chat, rooms, and one-click launching for your favourite
source ports (Zandronum, Odamex, GZDoom, UZDoom, ZDaemon, Chocolate Doom, Crispy Doom and more).

This repository only hosts **releases** of the Doom Hub client. There is no source code here.

## Download

Get the latest `DoomHub.exe` from the [Releases](../../releases/latest) page and run it. No installer is
needed. Your settings are kept in `%APPDATA%\DoomHub\DoomHub`.

Once you have Doom Hub, it updates itself: when a new version is out, it offers to download and install it.

## Is the download safe?

Every release is signed. Doom Hub checks the signature (`DoomHub.exe.sig`) before installing an update and
refuses any file that wasn't signed by the Doom Hub developer.
